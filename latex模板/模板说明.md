# 模板说明

本模板基于开源的 JXUSTmodeling 赛题模板重制：删除全部正文文字，保留章节骨架、导言区宏包与版式设置、参考文献样式，并按"每种格式只保留一个"的原则保留图表版式示例。示例图表的数据均为新造的占位数据，图片统一替换为白底黑字的 "KingL" 占位图（`figures/KingL.png`）。

## 一、保留的图表格式清单

### 表格（5 种，每种 1 个示例，均含占位数据）

| 编号 | 格式 | 位置（main.tex 内检索用 label） |
|------|------|------------------------------|
| T1 | 跨页长表 longtable（自动续表头、首尾粗三线） | `\label{tab:symbol}`（符号说明章）与 `\label{tab:codefile}`（附录A） |
| T2 | 全边框表格（`|c|` 竖线分列 + `\hline` + `\multicolumn` 横向合并行） | `\label{tab:boxed_demo}`（问题一·求解结果与分析） |
| T3 | 标准三线表（booktabs 的 `\toprule/\midrule/\bottomrule`） | `\label{tab:booktabs_demo}`（问题三·求解结果与分析） |
| T4 | 三线表 + 合并单元格（`\multirow` 纵向合并 + `\multicolumn` 横向合并 + 表中 `\midrule` 分组） | `\label{tab:multirow_demo}`（问题三·求解结果与分析） |
| T5 | 三线表 + 自动换行宽列（`p{9.4cm}` 限定宽度列 + 行间 `\addlinespace`） | `\label{tab:pcolumn_demo}`（问题三·求解结果与分析） |

### 图片（1 种启用 + 1 种预留）

| 编号 | 格式 | 位置 | 说明 |
|------|------|------|------|
| F1 | 单图定宽（`figure[H]` + `\includegraphics[width=…\textwidth]`） | `\label{fig:single_demo}`（模型准备·数据侧写） | 常用插图格式，保留一个示例 |
| F2 | 并排子图（`subcaption` 的 `subfigure` 环境） | 同位置**注释块**（未启用） | 需要并排子图时取消注释即可 |

### 公式

为便于复用保留了 3 个版式示例（内容为通用占位）：E1 多行变量定义块（`equation*` + `aligned`）、E2 单个编号公式（`equation` + `\ref` 引用写法）、E3 多行约束整合块（`cases`）。均位于问题一 Step1~Step4 对应位置。

## 二、AI 工具使用声明

- 位置：**正文（模型评价与推广）之后、参考文献之前**（检索 `\section*{AI工具使用声明}`），该位置为官方固定要求，不可移除。
- 按规定，使用 AI 的队伍除本声明外，还须在支撑材料中提交《AI工具使用详情》报告（模板见仓库 `AI使用报告模板/` 目录）。

## 三、附录

- **附录A 文件明细**：保留 longtable 文件清单格式，行内容为占位示例（当前列出 code/q1.m、code/q1.py）。
- **附录B 代码**：代码**不写在正文里**，统一用 `\lstinputlisting` 从专门的 `code/` 文件夹引入，一行命令即可拉入整个代码文件：
  ```latex
  \lstinputlisting[language=Matlab]{code/q1.m}   % B.1 MATLAB 代码
  \lstinputlisting[language=Python]{code/q1.py}  % B.2 Python 代码
  ```
  代码外观（黑色细边框、左侧行号、关键字蓝色、注释蓝绿色、字符串红色）由导言区 `\lstset` 统一控制，与正文其他位置保持一致。**替换为你自己的代码时**：把 `code/` 目录下的 `q1.m` / `q1.py` 换成实际代码文件（保持文件名不变），或修改 `main.tex` 附录B 中两处路径；每问一个文件（code/q1.m、code/q2.m……）即可，无需改动其他设置。按约定，附录只放代码清单，不含运行结果。

## 四、其他保留与处理

- 导言区宏包引用、`\lstset` 代码样式、enumerate 缩进恢复逐行保留；`\setCJKmainfont` 字体设置说明见本目录 `README.md`。
- 参考文献样式保留（`\section*{参考文献}` + `\refname` 清空 + `thebibliography` 手工条目），条目为 2 条 GB/T 7714 格式占位示例。
- 章节：section 级骨架与原模板一致（问题重述/问题分析/模型假设/符号说明/模型准备/问题一~四/模型检验与灵敏度分析/模型评价与推广）；各问 subsection 统一为"模型建立/模型求解/求解结果与分析"三段，题目特定的小节名已删除；问题一保留 Step1~Step4 求解分解小节样式。
- 目录：默认无目录页；如需可在导言 `\begin{document}` 后取消 `% \tableofcontents` 注释。
- `JXUSTmodeling.cls` 基于开源原版，仅增加西文字体回退（TeX Gyre Termes）并整理注释，排版行为与原版一致。
- 编译方式：XeLaTeX 两遍，或直接运行 `build.bat`（Windows）/ `build.sh`（macOS/Linux/Git Bash）。

## 五、环境要求与已知限制

- 目录结构：单文件 main.tex + JXUSTmodeling.cls + code/ + figures/；如需拆分多文件请自行调整。
- 中文字体设置 `\setCJKmainfont[...]{SimSun}` 依赖 Windows 自带字体（宋体/黑体/楷体）；非 Windows 环境需替换该行为本机可用中文字体，详见本目录 `README.md`。
- 编译引擎必须为 XeLaTeX（ctex + fontspec 依赖）。
