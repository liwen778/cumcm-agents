# 模板说明

本模板与仓库里的国赛模板（`latex模板/`）同一套版式：删除全部正文文字，保留章节骨架、导言区宏包与版式设置、参考文献样式，并按"每种格式只保留一个"的原则保留图表版式示例。示例图表的数据均为新造的占位数据，图片统一替换为白底黑字的 "KingL" 占位图（`figures/KingL.png`）。

与国赛模板相比只有结构性差异：**首页之后增加目录页、正文页码从 1 起算、AI 声明移到参考文献之后、附录增加软件与运行命令清单**，其余（字体、字号、行距、章节编号、图表标题、代码样式）完全一致。

## 一、页面结构（按官方规范顺序）

| 页 | 内容 | 页码 | 实现方式 |
|----|------|------|----------|
| 第 1 页 | 队伍编号 / 题号（取自官方 Word 模板）→ 论文题目 → 摘要 → 关键词 | 无 | `\begin{abstract}…\end{abstract}` |
| 第 2 页 | 目录 | 无 | `\mulu`（内部 `\pagestyle{empty}`） |
| 第 3 页起 | 正文 | 页脚中部，自定义域名从 1 开始连续编号 | `\mulu` 内 `\pagenumbering{arabic}` + `\pagestyle{plain}` |

- 全文**无页眉**（规范第 3 条），类文件用 `\AtBeginDocument{\pagestyle{empty}}` 保证前置页不出现页码。
- 目录默认只显示到二级标题（章、节），行距在目录内单独收紧到 1.15 倍，实战中约 35～45 条条目可稳定落在一页内；条目更多时可在导言区 `\setcounter{tocdepth}{1}`。
- 首页顶部"队伍编号 / 题号"用 `\mukuai` 输出；不需要时在导言区写 `\renewcommand{\mukuai}{}` 即可整块隐藏。

## 二、保留的图表格式清单

### 表格（5 种正文格式 + 2 种附录格式，均含占位数据）

| 编号 | 格式 | 位置（main.tex 内检索用 label） |
|------|------|------------------------------|
| T1 | 跨页长表 longtable（自动续表头、首尾粗三线） | `\label{tab:symbol}`（符号说明章）、`\label{tab:software}` 与 `\label{tab:codefile}`（附录A） |
| T2 | 全边框表格（列间竖线 + `\hline` + `\multicolumn` 横向合并行） | `\label{tab:boxed_demo}`（问题一·求解结果与分析） |
| T3 | 标准三线表（booktabs 的 `\toprule/\midrule/\bottomrule`） | `\label{tab:booktabs_demo}`（问题三·求解结果与分析） |
| T4 | 三线表 + 合并单元格（`\multirow` 纵向合并 + `\multicolumn` 横向合并 + 表中 `\midrule` 分组） | `\label{tab:multirow_demo}`（问题三·求解结果与分析） |
| T5 | 三线表 + 自动换行宽列（`p{9.4cm}` 限定宽度列 + 行间 `\addlinespace`） | `\label{tab:pcolumn_demo}`（问题三·求解结果与分析） |

### 图片（1 种启用 + 1 种预留）

| 编号 | 格式 | 位置 | 说明 |
|------|------|------|------|
| F1 | 单图定宽（`figure[H]` + `\includegraphics[width=…\textwidth]`） | `\label{fig:single_demo}`（模型准备·数据侧写） | 常用插图格式，保留一个示例 |
| F2 | 并排子图（`subcaption` 的 `subfigure` 环境） | 同位置**注释块**（未启用） | 需要并排子图时取消注释即可 |

### 公式

为便于复用保留了 3 个版式示例（内容为通用占位）：E1 多行变量定义块（`equation*` + `aligned`）、E2 单个编号公式（`equation` + `\ref` 引用写法）、E3 多行约束整合块（`cases`）。均位于问题一 Step1~Step4 对应位置。

## 三、AI 工具使用声明

- **位置：参考文献之后、附录之前**（检索 `\section*{AI工具使用声明}`）。这一点与国赛模板相反——国赛放在参考文献之前，MathorCup 规定放在**参考文献后**（《人工智能工具使用规定（试行）》第三条），不可混用。
- 模板给出两种写法，二选一：
  - 使用了 AI：列出工具名称、版本、使用环节、采纳与修改情况；
  - 未使用 AI：必须原样声明"本参赛队未使用任何AI工具"。
- 使用了 AI 的队伍还需做两件事：
  1. 在**参考文献**中增列工具条目（模板参考文献末尾有注释好的 `\bibitem`，取消注释即可），格式为 `[编号] 工具名称，版本/型号，开发机构/公司，使用日期`；
  2. 在支撑材料中提交《AI工具使用详情说明》（PDF）。
- 使用 AI 辅助编程时，还需在**程序注释**中说明 AI 辅助情况（工具名称、版本、开发机构、使用日期）。

## 四、附录

按规范"附录应提供实际使用的软件名称、命令和全部源程序"，本模板把附录拆成两块：

- **附录A 软件与文件明细**
  - `A.1 软件与运行环境`：longtable 列出软件名称、版本、用途（`\label{tab:software}`）；
  - `A.2 代码文件明细`：longtable 列出文件名与文件描述（`\label{tab:codefile}`）；
  - `A.3 运行命令`：`lstlisting` 给出可直接复现的运行命令。
- **附录B 代码**：代码**不写在正文里**，统一用 `\lstinputlisting` 从专门的 `code/` 文件夹引入：
  ```latex
  \lstinputlisting[language=Matlab]{code/q1.m}   % B.1 MATLAB 代码
  \lstinputlisting[language=Python]{code/q1.py}  % B.2 Python 代码
  ```
  代码外观（黑色细边框、左侧行号、关键字蓝色、注释蓝绿色、字符串红色）由导言区 `\lstset` 统一控制，与国赛模板逐字一致。**替换为你自己的代码时**：把 `code/` 目录下的 `q1.m` / `q1.py` 换成实际代码文件（保持文件名不变），或修改 `main.tex` 附录B 中两处路径；每问一个文件（`code/q1.m`、`code/q2.m`……）即可。按约定，附录只放代码清单，不含运行结果。

## 五、其他保留与处理

- 导言区宏包引用、`\lstset` 代码样式、enumerate 缩进恢复逐行保留自国赛模板。
- 参考文献样式保留（`\section*{参考文献}` + `\refname` 清空 + `thebibliography` 手工条目），条目格式按 MathorCup 规范写成中文标点、无 `[J]/[M]` 标识的样式；正文引用为上标方括号（类文件 `\setcitestyle{square,super}`）。
- 章节骨架与国赛模板一致（问题重述/问题分析/模型假设/符号说明/模型准备/问题一~四/模型检验与灵敏度分析/模型评价与推广）；各问 subsection 统一为"模型建立/模型求解/求解结果与分析"三段；问题一保留 Step1~Step4 求解分解小节样式。
- 目录不含"参考文献/附录/AI 声明"以外的星号标题：参考文献由类文件自动写入目录，AI 声明与附录按惯例不列入目录（需要时在对应 `\section*` 前加 `\phantomsection\addcontentsline{toc}{section}{标题}`）。
- 编译方式：XeLaTeX 两遍，或直接运行 `build.bat`（Windows）/ `build.sh`（macOS/Linux/Git Bash）。

## 六、环境要求与已知限制

- 目录结构：单文件 main.tex + MathorCupmodeling.cls + code/ + figures/；如需拆分多文件请自行调整。
- 中文字体由类文件自动选择：Windows 用系统宋体/黑体/楷体/仿宋（PDF 中文可复制、可检索），非 Windows 回退 Fandol 开源字体族，两种情况均无需手动设置。
- 编译引擎必须为 XeLaTeX（ctex + fontspec 依赖）。
- 正文篇幅按规范控制在 30 页左右；本骨架约 8 页，可作为篇幅与节奏的参照。
