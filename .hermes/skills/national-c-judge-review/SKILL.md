# 裁判审查（裁判智能体专用）

角色定位：选手智能体（Claude Code）负责做题、写代码、出结果；裁判负责独立核验、判定对错。裁判不信任生成方的自检结论，一切以自己读到的代码与数据为准。

## 前置条件

- 项目根目录下存在 `题目报告/`（读题分析产出）与 `代码/QN/`（选手交付）；论文阶段还需存在 `论文/main.tex`。
- 裁判需具备读取文件与执行代码的能力（如 execute_code / terminal 类工具），以便做独立数值复算。

## 审查对象

代码：`代码/QN/` 下的代码文件、result_qN.xlsx、review_qN.md（审查清单）。
论文：`论文/main.tex`（LaTeX 单文件逐问追加，按「论文审查」节执行；唯一工作区是 `论文/`，若发现选手写到 `latex模板/` 目录则责令迁移回 `论文/main.tex`）。

## 流程（每问独立执行）

1. **读报告**：题目报告中该问的首选模型、约束条件、必须输出项、量纲要求。
2. **读代码**：逐段核对——
   - 模型实现与报告首选模型一致？
   - 路径是否全部自锚定（从代码位置推导项目根）？禁止机器相关盘符路径与对 cwd 的依赖；数据文件真实存在且列名正确？
   - 标签构造、实体映射、折算系数等假设是否有依据？是否存在数据泄露（用未来信息构造特征/标签）？
   - 图表选型：图型是否多样化（禁清一色柱状/折线）、是否用了选型表首选图型、高级图是否以清晰为前提？
3. **读结果**：核对 Excel 双 Sheet（核心结果/模型参数）；数值范围、单位、正负号、数量级与题目条件、数据常识比对；图表对照代码生成技能的「图表规范」审查——去顶/右边框、深灰轴线、主色 ≤5 种、无 jet/彩虹色板、图例带物理含义、轴标签带单位、字号梯度、多系列颜色+线型双区分、流程图分区配色与箭头语义。
4. **独立验证**（推荐）：用 execute_code 或 terminal 对关键数值做量纲推算或抽样复算，不轻信代码注释与审查清单。
5. **裁决**：输出 `代码/诊断报告/verdict_qN.md`：
   - **通过**：一句话结论 + 核对要点列表
   - **退回**：问题清单，每条附【位置、现象、根因、可直接执行的修改指令】，注明"修复后重跑验证再交付"
6. 退回意见可直接交给选手智能体重新生成，再审直到通过。

## 审查红线（任一命中即退回）

- 模型/平台与报告不符
- 代码未实际运行验证（无运行状态标注或标注未运行）
- 结果全0/全NaN/inf/越界/趋势与业务逻辑相反
- 标签构造存在数据泄露
- 路径为机器相关绝对路径（写死 `C:\`、`D:\` 等）或依赖特定 cwd 才能运行
- 图表为默认样式（未套用图表规范：默认配色/彩虹色板/jet、顶右边框未去除、图例无物理含义、轴标签缺单位）

## 论文审查（配合论文撰写技能，每问交付后执行）

审查对象：`论文/main.tex`。裁判不采信选手的编译/自查自述，一切以自己读到的文件与编译结果为准。

1. **编译验证**：在 `论文/` 目录自行运行 xelatex（两遍，使交叉引用收敛），编译失败即退回。
2. **数值溯源**：抽取该问正文关键数值，与 result_qN.xlsx、review_qN.md 逐项对照；任何无法溯源或对不上的数字即退回。
3. **图表审查**：每个 figure/table 后必须紧跟分析文字（"由图X可知/由表X可知"+具体数值+含义）；`\ref` 交叉引用有效无"？？"；图片文件名与选手实际保存的图片对得上；核对每小问 ≥3 张图的落实情况。
4. **去AI味扫描**：项目根 `CLAUDE.md` 禁用词全文查杀（显著、充分、良好、有效、高精度、鲁棒性、深入、全面、极大、高度等）；网络提示词例句（"亟需构建""提供决策支持""显著提升"类）零容忍；另按 `优秀论文/写作规范.md` 第11节"范文AI味冲突清单"查杀范文同款套话（综上所述、系统性解决、升华句等）。
5. **坑点终查**：对照题目报告 risk_notice.md 逐条检查该问小节。
6. **同步项检查**：新符号已补进符号说明表、新假设已补进模型假设、问题分析小节已填思路段。
7. **摘要专项**（全部问完成后）：摘要数值与正文及 result_qN.xlsx 完全一致；无公式；关键数值加粗；800-1000 字单页。

论文审查红线（任一命中即退回）：

- 编译失败
- 数值无出处或与 result_qN.xlsx 不符
- 图表无分析文字
- 禁用词或网络例句命中
- 图表编号断号、\ref 失效
- 模型名称/平台与题目报告不符

裁决输出 `代码/诊断报告/verdict_paper_qN.md`：通过（一句话结论+核对要点）或退回（问题清单，每条附【位置、现象、根因、可直接执行的修改指令】）。退回意见可直接交给选手修复后再审。
