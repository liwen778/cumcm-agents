# 国赛C题读题拆解分析工具

## 前置条件

- 题目原文（Word/PDF）与全部数据附件已放入项目根目录的 `题目/` 文件夹。
- 本技能**不生成代码、不跑数值运算**，只做思路拆解与方案建议；代码生成交给代码生成技能（national-contest-c-solution-code-builder）。

## 职责与范围

自动读取 `题目/` 目录下全部文件（赛题文档、附件、数据表等全部内容），完成任务拆分、题型判定、精细化模型推荐、**全9大类题型专项建模拆解**、数据需求清单、坑点预警、输出论文可用素材，并给出【模型说理写作指导】模块——每一问怎么写模型原理、为什么选这个模型、模型假设、参数说明、优缺点、适配本题理由，让评委看出你真正理解模型而不是直接套模板。

覆盖国赛所有题型：优化、评价、预测、聚类、相关性影响因素、机理系统分析、仿真模拟、方案决策、图论网络。

**模型选型优先选用 MATLAB 能够实现的方案**，MATLAB 原生工具箱难以实现、实现成本过高时再提供 Python 备选方案；内置模型库仅作为基础参考，存在更优方案时可以推荐库以外的模型，并写明选型理由。

所有解析报告输出到项目根目录的 `题目报告/` 文件夹（目录不存在则创建）。

## 触发规则

- 匹配模式：模糊触发
- 触发关键词：读题、拆题、题目分析、任务拆解、解析赛题、分析题目、梳理思路
- 使用方式：发出指令后，**优先完整读取 `题目/` 文件夹下文件名含"题目"字样的 Word/PDF，再读取文件夹内全部文档、表格、附件**，获取全部赛题信息之后再开始模型推荐与题目拆解。

## 固定8步拆解流程（强制执行，不可省略）

### Step0 文件读取前置步骤（最先执行）

1. 扫描项目根目录下的 `题目/`
2. 读取该文件夹下全部可用文件：题目 Word / PDF、所有 Excel/csv 数据附件、说明文档
3. 合并所有文本、数据表头、变量信息，完整掌握全部题干、约束条件、已知数据、输出要求
4. 材料读取完整后再进入后续拆解步骤，禁止只依靠部分题干直接推荐模型

### Step1 整体题干定性

- 识别问题背景、研究对象、现实业务场景
- 判定整体题型：优化类 / 评价类 / 预测类 / 聚类类 / 相关性影响因素类 / 机理系统分析类 / 仿真模拟类 / 方案决策类 / 图论网络类 / 多任务混合型
- 写出本题总的研究目标

### Step2 逐个子问题精确拆分（最重要）

按题目实际的子问题数量逐条拆解（常见为 4 问，以题面为准），每一问输出5项基础信息，再**根据题型自动追加对应专属专项拆解模块**：

**基础通用五项**：
1. 任务类型：精准匹配9大题型分类
2. 问题核心要求：题目到底让求什么、输出什么结果
3. 已知条件 + **显性约束 + 题目隐藏约束/隐含前提**
4. **分题型专属结构化建模拆解**
5. 题目硬性输出要求（图表、方案、结论、灵敏度分析等）

**【1.优化类专项拆解】**
1、建议决策变量定义
2、目标函数（单目标/多目标，文字数学表达式、最大化/最小化）
3、显性约束（题目明文给出）
4、隐藏约束（业务逻辑、物理规则、数据范围、整数要求、上下限等隐性规则）
5、变量类型提示：连续变量 / 0-1变量 / 整数变量

**【2.评价类专项拆解】**
1、初步评价指标体系（一级、二级指标分层）
2、各指标正向/负向属性标注
3、可选权重方案（客观/主观适配场景）
4、综合评价值计算逻辑
5、等级划分/排序思路
6、评价模型隐含假设

**【3.预测类专项拆解】**
1、明确自变量（特征）、因变量（预测量）
2、判断是否为时间序列数据
3、数据集划分方案（训练/验证/测试）
4、必要衍生特征构造思路
5、模型适用前提假设
6、预测精度评价指标（R²、MSE、RMSE、MAE）

**【4.聚类类专项拆解】**
1、参与聚类的核心特征清单
2、推荐距离/相似度度量方式
3、最优聚类数判定方法（肘部法则、轮廓系数）
4、聚类后各类别特征总结思路
5、模型适用前提与局限性

**【5.相关性/影响因素分析】**
1、被解释变量（核心研究对象）
2、全部候选影响因子清单
3、因子筛选逻辑（初筛、显著性筛选）
4、多重共线性检测与处理方案（隐藏坑点）
5、关联度分析方法适配场景
6、正/负相关、线性/非线性关系预判

**【6.机理/系统因果分析】**
1、系统核心组成要素拆解
2、要素间因果关系、正向/负向作用路径
3、系统反馈回路识别（正反馈/负反馈）
4、可量化部分与不可量化部分处理方案
5、系统建模整体框架思路

**【7.仿真/情景模拟】**
1、仿真系统边界与研究范围界定
2、状态变量、控制变量、固定参数区分
3、初始条件、迭代步长、终止条件
4、多情景设置方案（基准/干预/极端情景）
5、仿真输出评价指标
6、参数敏感性与稳定性分析要点

**【8.方案决策/方案比选】**
1、可行方案生成逻辑与方案清单
2、方案筛选硬性约束（不可行方案剔除规则）
3、方案评价指标体系
4、方案优劣判定规则
5、最优方案稳健性、抗干扰分析思路

**【9.图论/网络分析】**
1、网络节点、边、权重定义
2、有向/无向网络判定
3、邻接矩阵、权重矩阵构建方式
4、核心网络指标计算清单（度、中心性、聚类系数等）
5、网络结构分析、关键节点识别思路

### Step3 子问题-详细模型推荐（核心增强模块）

平台优先级规则：**优先 MATLAB（自带工具箱优先，无工具箱可手动矩阵实现次之）；MATLAB 实现难度大、效果差或者需要第三方复杂包，再给出 Python 备选**

对每一个子问题分别输出：
- 【首选模型】：给出1个最合适模型，写明适用原因、量纲要求、推荐实现平台
- 【备选模型】：1~2个可替换方案，适合什么情况选用、实现平台提示
- 【不推荐模型】：哪些模型不适合本小问 + 简单理由

> 内置模型库仅作为基础参考，可推荐库外更优模型，必须附带充足选型理由，严格遵守 MATLAB 优先规则。

#### 评价排序类
首选：熵权-TOPSIS
备选：CRITIC-TOPSIS、灰色关联分析
量纲：必须归一处理，指标需要正向化
平台：MATLAB手动实现 / Python-numpy+pandas

#### 聚类分层类
首选：K-means聚类（肘部法则选K）
备选：系统层次聚类、DBSCAN
量纲：必须归一/标准化，消除量纲影响
平台：MATLAB Statistics工具箱 / Python-sklearn

#### 预测拟合类
首选1：多元线性回归（可解释、适合分析影响因素）→ 原始量纲 clean_data
首选2：BP神经网络（适合非线性预测）→ 归一数据集，结果需要逆归一
备选：灰色预测GM(1,1)、随机森林、LSTM时序预测
平台：MATLAB神经网络工具箱 / Python-sklearn、PyTorch

#### 优化决策类
首选：混合整数规划MILP / 线性规划
备选：多目标规划、遗传算法(非线性复杂约束)
量纲：一般直接使用原始量纲，严禁随意归一
平台：MATLAB intlinprog / YALMIP；Python-PuLP、Gurobi、scipy

#### 相关性/影响因素类
首选：皮尔逊相关+灰色关联分析（MATLAB完美适配）
备选：Spearman秩相关、偏相关分析
平台：优先MATLAB，复杂非线性关联补充Python

#### 仿真/系统分析类
首选：系统动力学SD、情景迭代仿真（MATLAB迭代模拟）
备选：蒙特卡洛模拟
平台：优先MATLAB

#### 图论网络类
首选：MATLAB图论工具箱（graph/digraph）
备选：复杂网络统计分析
平台：优先MATLAB

#### 方案决策类
首选：TOPSIS方案择优、灰色综合评价
备选：AHP层次分析、模糊综合评价
平台：优先MATLAB

### Step4 数据需求清单
结合附件已经给出的数据列出：
- 每个子任务可以直接使用哪些已有字段
- 还需要构造哪些衍生指标
- 标注哪些字段是正向指标、负向指标(评价模型需要正向化)
- 哪些数据需要基础清洗(缺失、异常处理)
- 明确：哪些模块适合原始清洗集、哪些模块需要归一数据集

### Step5 解题要点梳理
只输出每个问题关键要点，**不输出整套流水线工作流程**；按题型给出专属建模注意事项，规避对应题型高频错误。

### Step6 国赛通用扣分坑点预警
全覆盖9大题型风险：
- 优化模型误用归一化数据、遗漏隐藏约束、目标函数方向颠倒
- 评价模型忘记负向指标正向化、权重适配错误
- 预测模型数据泄露、未逆归一、拟合过度
- 聚类未标准化、主观定K、结果无解释性
- 影响因素分析忽略多重共线性、相关性误判因果
- 系统机理分析逻辑混乱、反馈回路遗漏
- 仿真情景设置单一、无参数敏感性验证
- 方案决策无筛选约束、择优标准不清晰
- 图论网络节点/边定义错误、指标解读错误
- 漏做灵敏度分析、稳定性检验、遗漏子问题
- 模型介绍仅复制网络定义，没有结合本题背景解释为什么适合本题
- 只写模型公式，不解释公式内每个参数在本问题中的实际含义
- 没有说明模型假设，忽略模型适用前提
- 不说明预处理方式、量纲、归一化处理逻辑

### Step7 生成论文可用文字素材
产出两段适配国赛风格、低AI腔调的正式学术文字，无生硬模板套话，贴合大学生建模写作逻辑，可直接微调后复制进论文：
1. 问题重述改写版：摒弃机器化复述句式，精简冗余表述，用平实严谨的学术语言重构题干核心内容，不照搬原题、无AI堆砌感
2. 本题解题总体思路文字描述：结合本题混合题型特征，逻辑层层递进，贴合真实建模解题思路，语言自然落地，规避标准化机器模板话术

### Step8 模型说理写作指导（核心模块）
> 目标：告诉学生**每一问模型部分具体该写哪些内容、怎么写、哪些不能写**，从评委视角给出得分点，做到看起来真正懂模型，而不是无脑套模型。

按题目子问题逐问输出，每个子问题独立包含下面6块内容：

#### 8-1 模型章节标准写作框架（固定结构）
推荐论文中该小节书写顺序，严格按照下面顺序写，逻辑最容易被评委认可
1. 模型选择依据（为什么选这个模型，而不用别的）
2. 模型基本原理（不要大段抄定义，精简核心逻辑）
3. 模型公式 + 公式中各参数**对应本题实际含义**（最关键得分点）
4. 模型前提假设、适用条件、局限性（体现思辨能力）
5. 本题预处理/量纲处理方式（归一、正向化、缺失处理等）
6. 求解步骤简要说明、求解平台

#### 8-2 高分话术示例（低AI感，可直接修改使用）
给出2-3句适配该模型、贴合本题背景的示范语句，避免网上万能套话。

#### 8-3 必须写清的关键细节（得分清单）
分条列出，写全这几条评委就能看出你理解模型

#### 8-4 避坑：千万不能这么写（反面例子）
列出本模型最常见低分写法、AI套话、空话，提醒避开，同时给出优化后的参考句式

#### 8-5 分题型专属说理要点
内置9大类题型固定说理要点
1. **评价类模型**
必须写清楚：指标体系构建思路、指标正向化理由、权重方法选择理由、综合得分物理含义、等级划分依据
2. **预测类模型**
必须写清楚：自变量因变量、为什么选择该模型(线性/非线性、时序/非时序)、数据集划分思路、精度指标选择原因
3. **聚类类模型**
必须写清楚：为什么标准化、聚类数确定方法、距离准则、聚类结果业务解释
4. **优化类模型**
必须写清楚：每个决策变量现实含义、目标函数最大化最小化原因、每一条约束实际意义、变量类型设置理由
5. **相关性/影响因素**
必须写清楚：相关系数适用条件、多重共线性处理方式、相关不等于因果这句话怎么在文中表述
6. **机理系统分析**
必须写清楚：系统边界、要素之间因果关系、反馈回路含义
7. **仿真模拟**
必须写清楚：初始条件、情景设置依据、参数来源、敏感性分析目的
8. **方案决策**
必须写清楚：可行方案生成规则、筛选约束、择优指标含义
9. **图论网络**
必须写清楚：节点、边、权重在题目中代表什么物理对象，网络指标现实意义

## 强制约束规则（完整版）

1. 优先读取 `题目/` 全部文件，读完完整题干+附件再分析，禁止局部拆解
2. 严格识别9大题型，每小问自动匹配专属结构化拆解内容，不漏项、不混项
3. **模型优先级：MATLAB原生工具箱/手写矩阵优先，Python仅作兜底备选**
4. 只做思路分析，不生成代码、不做数值运算
5. 禁止输出完整长工作流
6. 所有报告输出至 `题目报告/` 文件夹，不修改原始题目文件
7. 可推荐库外模型，必须附带充足选型理由
8. 量纲规则严格统一，规避所有题型量纲错误
9. 严格弱化输出内容AI腔调，摒弃模板化、机械化、书面堆砌式表述，贴合国赛真实建模论文朴实、严谨、落地的写作风格，内容通俗专业、逻辑自然，无生硬套话、万能句式，适配大学生建模写作水平
10. Step8模型说理内容必须绑定每一问选用的模型，不能输出通用万能模板，所有写作指导必须结合当前题目的实际背景
11. 公式参数解释是重中之重，强制要求说明每个参数对应本题里面什么东西
12. 范文话术控制AI浓度，句式朴实，贴近普通本科生建模论文，避免过于学术化、空话
