# 优秀论文目录说明

本目录存放**写作范式依据**《写作规范.md》——从公开的优秀论文中蒸馏出的结构、句式与检验写法，是论文写作技能（national-c-paper-writer）与裁判审查技能共同引用的唯一范式文件。

## 范文 PDF 不入库

往年优秀论文的 PDF 与提取文本受作者版权保护，本仓库**不收录**。如需对照原文：

1. 自行从官方/公开渠道收集范文 PDF 放入本目录（请自行确认使用范围）；
2. 用文本提取工具得到纯文本后，可按《写作规范.md》开头的维度重新蒸馏，替换出属于你自己队伍的写作范式。

不放范文也不影响使用：写作与审查流程只依赖《写作规范.md》本身。
