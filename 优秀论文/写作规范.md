**国赛固定骨架（按此顺序写）**：
摘要 → 一、问题重述（1.1背景 / 1.2问题要求，可加1.3总体技术路线+思路图） → 二、问题分析（每问一节） → 三、模型假设（条目式） → 四、符号说明（三线表） → 五、问题一模型建立与求解 → 六、问题二…（逐问） → 模型的分析与检验（灵敏度/稳健性） → 模型的评价与推广（优点/缺点/推广） → 参考文献 → 附录。

## 2. 摘要写法

四篇共性结构，严格四段：

**第1段（1-2行）**：场景+研究对象+总体手段。句式模板：
> 本文针对……（题目场景），在不同情况下建立了……模型，并利用……算法求解……，为……提供决策参考。

**第2~N段（每问一段）**：`针对问题X，本文……` 开头，格式固定为 **做了什么 → 用了什么模型/方法 → 关键结果数值**。数值必带，单位必带。
- 烟幕国一：`对于问题一，本文首先建立了……运动学模型；然后分析……，运用凸集理论，得出了……结论，利用该结论建立了……判定模型。……代入已知参数可得有效遮蔽时长为1.3916s。`
- NIPT：`针对问题一，本文构建了"多元线性回归-非线性多项式回归-线性混合效应-非线性混合效应"四层次模型……结果表明，……（p=2.96E-06）……`
- 蔬菜：`针对问题二，……以利润最大化为目标函数……求解出未来一周最大收益为5105.60元，最后引入模拟退火模型求出最优的……策略。`

**最后1句**：模型评价收束。句式：`最后，本文通过……方法，系统性地解决了……。对模型的灵敏度进行分析，验证了模型具有较好的鲁棒性。` 或 `最后本文对所建立的模型进行了讨论和分析，综合评价了模型的优缺点。`

**关键词**：4-5个，含核心模型词（如：粒子群优化、贪心策略、混合整数规划、K-means）。用空格或分号分隔。

⚠️ CLAUDE.md 禁止的摘要句（范文有但不得抄）："综上所述，本研究通过层级化模型设计…确保了…稳健性与实用性""该研究不仅揭示了…显著优势，还为未来…提供了参考"——这类升华句用"最后本文对模型进行了讨论和分析，综合评价了优缺点"替代。

## 3. 问题重述

**1.1 问题背景**：2段。第1段领域背景+文献引用[1][2]；第2段本题定位+研究目标（写具体应用价值：为商超定价/为无人机防御/为临床检测提供方案）。禁止"该问题具有重要的现实意义"式空泛句。

**1.2 问题要求**：把题目每个问题改写为"问题X：在……条件下，确定/计算/给出……"。必须带题目给的关键数值参数（速度、半径、数量、区间）。原文改写而非照抄。

可选 **1.3 总体技术路线**：一张思路流程图（图1）+ 一句"本文整体技术路线如下图1所示"。

## 4. 问题分析（重点，范文学得最多的地方）

每问一节（2.1/2.2/…），三篇国一都写足。**结构：问题定位 → 关键难点 → 方法选择理由（扣本题数据/物理特征）**。

句式模板（烟幕国一原句）：
> 问题一要求在……前提下，求解……。**关键在于**……的确定，……则可以根据其给出。由于……，因此需根据……建立……模型。……，即可得到……。

问题间衔接句（必用，形成闭环）：
- `问题二建立在问题一的基础之上，要求……`
- `问题三是问题二的扩展和延伸，相较于前两问，……`
- `问题四可视为若干个问题二的组合。相较于问题二，……`
- `与问题四类似的是，问题五也具有较大的规模，故可借鉴问题四中的方法……`

分析段要点：
- 必须落到本题具体对象：烟幕篇讲"烟幕遮蔽的临界条件""各物体的运动学规律"；NIPT讲"孕周数据的连续性转换、数据有效性筛选、异常值处理"三个数据问题；华数杯讲"预测与容量约束保持一致"。
- 方法选择必须给理由且理由扣题：`由于该问题为多变量非线性优化问题，目标函数无显式解析表达式，传统的解析方法或基于梯度的优化方法难以直接求解`。
- 优化类题在分析段预告"关键在求解部分"：`问题四的关键在于求解部分，由于决策变量较多，导致问题规模较大，可能需要将其分解为若干个子问题`。
- 可以配一张思路流程图（NIPT版图2、华数杯图1），图上写清楚：输入 → 处理方法 → 输出。

## 5. 模型假设与符号说明

**模型假设**：条目式 `1．假设……`。每条假设都是模型简化的显式声明，且**必须与模型评价的"缺点"一一对应**（烟幕篇假设"不考虑空气阻力"，缺点就写"忽略空气阻力和风向可能导致偏差"）。假设数量 4-8 条。

**符号说明**：三线表，列 = 符号/含义/单位。只收正文实际用到的符号；同一个符号含义变更时（如tdrop/起爆时刻）用上下标区分，在表中全部列出。

## 6. 每问模型建立与求解（七步闭环）

### 6.1 问题定位（1-2句）
`问题X要求在……条件下……`，指明本问输出什么。

### 6.2 分析先行
为什么用这个模型，必须扣本题数据特征与约束。禁止"XX模型是一种常用方法"式开头。NIPT范例：
> 从临床背景可知，Y染色体浓度是衡量NIPT准确性的关键指标（男胎需≥4%）……从数据维度看，需先解决三个关键问题：一是……二是……三是……

### 6.3 模型建立
- 分小节（5.1.1/5.1.2/…），每节一个小模型，层层递进（运动学→几何临界→判定→计算）。
- 公式分步推导带编号 `(1)(2)…`；**每个公式的每个参数写明对应本题哪个实际对象**（烟幕篇：`区域r在小时t的碳排放量由电网碳强度ρrt与设施总功率决定`）。
- 每条约束后跟现实含义（华数杯：`题目要求新能源全部就地消纳，即区域设施负荷不得超过新能源与购电上限之和`）。
- 数据口径论证要写（华数杯范例）：`若直接按整小时统计到达量，会丢失任务跨小时占用的信息`→给出重叠比例公式→`按此口径计算的系统占用需求序列，一阶自相关系数约为0.761；仅统计到达量时该系数接近0`。

### 6.4 求解方法
- 算法选择理由（1-2句）→ `该算法的求解步骤如下`。
- **Step1/Step2/…分解，每步带代码真实参数**（烟幕篇原句）：
  - `Step1：参数设置。设定粒子数为50，最大迭代次数为200。……惯性权重和学习因子分别取w=0.8，c1=1.2，c2=1.2。`
  - `Step2：初始化。在给定范围内随机初始化粒子的位置与速度。`
  - `Step3~Step6：……直至迭代次数达到100次，得到全局最优解。`
  - 离散化参数必写：`时间步长取∆t=0.0001s`、`在两圆周上均匀地取i=100个点`。
- 迭代公式带编号（PSO速度/位置更新式(21)(22)），注明 `r1, r2~U(0,1)`。

### 6.5 结果呈现
- 三线表（booktabs）或 figure 环境；图题在图下方，表题在表上方。
- 图解读句式（烟幕篇原句）：
> 运行MATLAB，得到遮蔽时间tcover随迭代次数的变化，如图5所示。观察图5可知，随着迭代次数的增加，有效遮蔽时间从0迅速攀升，并通过不断更新局部最优解逐步得到全局最优解，最终使曲线稳定在了所求的最长遮蔽时间tcover=4.585s。
- 表解读句式（NIPT篇）：先引表 `如表3所示`，再逐项解释：`M1与M2的R²仅为0.0457、0.0549，意味着……核心原因是……；而M3、M4引入孕妇个体分组后，R²跃升至0.7983、0.8037……`——**先摆数值，再解释机理原因**。

### 6.6 结果分析
- 逐项解读 + 回扣题目要求；bullet列表适合时段类结果（烟幕篇）：
> 在爆炸后2.9565~4.2892s时间段内，……此时属于情况2；……综上，烟幕干扰弹对导弹M1的有效遮蔽总时长tcover=1.3916s。
- 模型检验跟在对应结果后面写（不设独立检验章）；若全文末有统一检验章，每问结果内也要有与题目要求的对照句。

### 6.7 小结+衔接
本问结论一句 + 为下一问提供什么输入。模板：`该模型即为……模型，将待确定的变量作为决策变量，并根据题目中的限制列出约束条件`。

## 7. 模型的分析与检验（末章，三种写法视题目而定）

### 7.1 灵敏度分析（优化/物理类题必写，烟幕篇范例）
1. 选特征对象：`选择具有显著空间位置特征的两架无人机，靠近导弹轨迹的F1和远离导弹轨迹的F2`。
2. 定扰动：`对速度上界或速度下界施加−10%~10%的扰动`，指标为`单次投放烟幕干扰弹造成的有效遮蔽时间`。
3. 消除算法偶然性：`通过加大粒子种群数、迭代次数，并多次更换种子求解`。
4. 结果+机理解释：`两架与导弹轨迹距离有显著差异的无人机，在面对小范围波动时，其有效遮蔽时间波动均未超过3%。其稳定的核心在于该模型具有大量局部最优点，同时这些局部最优点与全局最优点的差异较小……故该模型十分稳定，具有鲁棒性。`

### 7.2 稳健性检验（数据/机器学习类题必写，NIPT篇范例）
- **参数敏感性**：`改变聚类簇数（K=2至K=8）与达标比例（q=0.80、0.90、0.95）进行敏感性测试。结果显示……q从0.80提升至0.95时，推荐时点仅延迟1-2周，无突变波动`。
- **误差扰动**：`基于蒙特卡洛模拟（1000次扰动），对孕周（±0.43周）、BMI（±0.6kg/m²）、浓度（±0.5%）加入随机误差后……95%置信区间宽度均小于2周`。
- **超参扰动**：`通过调整学习率（10⁻⁵至10⁻³）与Dropout系数（0.2至0.5）测试，发现测试集准确率波动范围仅为0.95-0.97，召回率波动范围0.88-0.92`。

### 7.3 模型合理性分析（NIPT篇独有，可借用）
- 变量选择合理性：临床/物理依据 + 相关性检验排除无关变量（`经相关性分析|r|<0.05`）。
- 模型结果合理性：结构优化路径 + 指标提升链（`通过R²（从0.0457提升至0.8037）验证了结构优化对拟合效果的提升`）。

## 8. 模型评价与推广

**优点**（编号列表，每条必须扣具体机制，禁止空泛）：
- 模型由简到繁、层次分明，便于推广（烟幕：单机单弹→单机多弹→多机协同→全局）。

## 9. 句式特征库（范文原句，直接套用）

**图/表引用**：`如表3所示` / `由图X可知` / `观察图X可知` / `运行MATLAB（Python），得到……，如图X所示`。
**结果收束**：`综上，……总时长tcover=1.3916s` / `最终得出……为20.675s`。
**结果解释**：`R²反映模型对……的解释能力，取值越接近1说明拟合效果越好`；先摆数值后解释机理。
**多问衔接**：`问题二建立在问题一的基础之上` / `问题是问题二的扩展和延伸` / `可视为若干个问题二的组合`。
**求解衔接**：`因此，我们选择PSO作为问题二的优化工具` / `该算法的求解步骤如下`。
**数据特征**：`一阶自相关系数约为0.761` / `AI训练任务数量占三类任务总量的33.1%，GPU总需求却占全部需求的80.1%，单任务GPU均值71.28，是实时推理（4.02）的17.7倍`——用比率和倍数说话。

## 11. 与 CLAUDE.md 的冲突处理

范文中的这些句子**被 CLAUDE.md 禁止，不得照抄**：
- `综上所述`（华数杯/NIPT摘要均有，全篇限≤2-3组，摘要内不用）
- `系统性地解决了……显著优势`（烟幕摘要升华句 → 改用"最后本文对模型进行了讨论和分析，综合评价了优缺点"）
- `深入`/`全面`/`显著提升`类修饰（NIPT里"有效平衡了……临床需求"可保留动词+数据版本）
- 模型"具有较高精度和可靠性"式定性评价 → 必须换成具体指标（R²=0.8037、WAPE=14.13%）
