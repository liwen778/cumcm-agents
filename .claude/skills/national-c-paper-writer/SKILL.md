# 国赛C题论文撰写（LaTeX 逐问版）

## 定位

流水线最后一环：消费读题分析与求解代码的产物，产出 LaTeX 论文。只写正文（模型建立与求解、摘要、问题重述/分析/假设/符号说明）；**参考文献与附录不写**，只留 `% TODO` 占位注释。

## 前置条件

- `latex模板/` 目录完整（`JXUSTmodeling.cls` + `main.tex` 干净骨架）——论文母本来自这里。
- 已完成至少一问的求解：`代码/QN/result_qN.xlsx` 与 `代码/QN/review_qN.md` 存在。
- xelatex 可用（TeX Live 或 MiKTeX；验证方式见 `latex模板/README.md`）。

## 输入（写作前强制完整读取）

1. 用户指令，如"问题一我用了XX模型，写论文"
2. `题目报告/` 全部文档，重点三份：
   - `model-writing-guide.md`：模型说理写作框架（选择依据→原理→公式+参数落地→假设局限→预处理→求解说明），直接作为写作骨架
   - `risk_notice.md`：扣分坑点清单，每问写完逐条自查
   - `task_split.md`、`model_suggest.md`：约束条件、硬性输出要求、模型选型结论
3. `代码/QN/result_qN.xlsx`：论文数值唯一来源
4. `代码/QN/review_qN.md`：关键假设与结论出处
5. 项目根目录 `CLAUDE.md`：去AI味写作规范，全文强制执行

## 铁则（违反任何一条即返工）

1. **单文件逐问**：论文目录只有一个 `main.tex`，逐问追加；基于 `JXUSTmodeling.cls`。**唯一工作区是 `论文/`**，main.tex、figures/、编译全在这里进行，禁止写到 `latex模板/` 目录（那里是母本，保持干净）
2. **逐问等确认**：每写完一问（编译通过）交用户审；用户明确说写下一问才继续；已写内容不改（用户点名要求除外）
3. **数值零凭空**：论文中每个数字必须能在 result_qN.xlsx / review_qN.md / 题目报告 中找到出处；禁止编造数值，禁止为排版好看改动数据
4. **先编译后交付**：xelatex 编译无 Error 才算交付；报错必须修复后再交
5. **图表必带分析**：每个图/表后紧跟一段分析文字（"由图X可知…"，含具体数值+含义）；无分析不允许交付
6. **范式强制**：《优秀论文/写作规范.md》是唯一写作范式依据，章节骨架、摘要四段式、问题分析句式、七步闭环、Step参数化、图表分析、末章检验/评价写法全部按规范执行，违反即返工；CLAUDE.md 禁用词全部执行；句式对齐规范第9节句式特征库（"由表X可知""观察图X可知"+数据）；网上提示词的例句（"亟需构建""决策支持""显著提升"类）一个不进论文
7. **报告为准**：模型名称、平台、约束与题目报告一致，禁止擅自换模型

## 开工准备（首次触发时执行一次）

1. 读 `优秀论文/写作规范.md`（写作范式蒸馏文档：全文骨架、摘要四段式、问题分析"关键在于"句式、七步闭环、Step参数化、灵敏度/稳健性检验写法、评价优缺点模板、句式特征库、范文AI味冲突清单）。写作全程以该规范为唯一范式依据；若用户在 `优秀论文/` 放了自己的范文 PDF，可参考但不必重读原文
2. 准备论文工作区：若 `论文/main.tex` 不存在，从 `latex模板/main.tex`（干净骨架母本）复制一份到 `论文/`，并把 `latex模板/JXUSTmodeling.cls` 一并复制到 `论文/`（或编译时在 `论文/` 目录保留类文件副本）；图片目录 `论文/figures/` 一并创建
3. 在 `论文/` 目录 xelatex 试编译（连跑两遍），确认模板可用后再开始写

## 每问写作流程（用户说"问题N用了XX模型"后执行）

1. 读取该问 result_qN.xlsx、review_qN.md、题目报告对应小问文档
2. 在 `main.tex` 的 `\section{问题N模型建立与求解}` 位置写入七步闭环：
   - ① 问题定位（1-2句：本问解决什么、输出什么；若为后续问，先写衔接句："问题N建立在问题N-1的基础之上，要求……"/"问题N是问题N-1的扩展和延伸"）
   - ② 分析先行（为什么用这个模型，必须扣本题数据特征与约束；句式套用写作规范："……关键在于……，……则可以根据其给出"；禁止"XX模型是一种常用方法"式开头）
   - ③ 模型建立（变量定义；公式分步推导带编号；**每个公式的每个参数写明对应本题哪个实际对象**；每条约束后跟现实含义；子模型用 5.1.1/5.1.2 分节层层递进）
   - ④ 求解方法（算法选择理由 1-2 句——非线性无显式表达式故弃解析法/规模大故分解降维；Step1/Step2/Step3 分解、关键参数用代码真实值：粒子数、最大迭代、惯性权重w/学习因子c1c2、随机种子、初温、收敛阈值、离散化步长∆t、采样点数等）
   - ⑤ 结果呈现（三线表 booktabs / figure 环境；`\includegraphics{文件名}` 用代码实际输出的图片名，图片由用户手动放入 `论文/figures/`，正文只负责占位与引用）
   - ⑥ 结果分析（"由表X可知"/"观察图X可知"逐项解读 + 回扣题目要求；**先摆数值，再解释机理原因**；图解读要描述曲线走向"从0迅速攀升……最终稳定在……"；模型检验跟在对应结果后面写，不设独立检验章）
   - ⑦ 小结+衔接（本问结论一句 + 为下一问提供什么输入，形成全文闭环）
3. 同步更新全文其他位置：新符号补进符号说明 longtable、新假设补进模型假设 enumerate、`\subsection{问题N的分析}` 填思路段（只写思路不写结果）
4. 对照 `risk_notice.md` 逐条自查本节，输出自查记录（坑点→本节处理方式）
5. xelatex 编译通过 → 交付用户审，说明本问写了什么、图表清单、待用户放入的图片文件名

## 末章：模型的分析与检验 + 模型的评价与推广（全部问写完、摘要之前）

全部问完成后写末两章，写法照《写作规范.md》第7、8节：

1. **模型的分析与检验**（`\section{模型的分析与检验}`，三种写法按题目类型取用）：
   - 灵敏度分析（优化/物理类题必写）：选特征对象（如靠近约束边界vs远离的实体）→ 定扰动（±10%）与指标 → 消除算法偶然性（加大种群/迭代/多次换种子）→ 结果波动数值 + 机理解释（"波动均未超过3%。其稳定的核心在于……"）
   - 稳健性检验（统计/机器学习类题）：参数敏感性（改变聚类簇数K、达标比例q、超参，看指标波动区间）+ 误差扰动检验（蒙特卡洛1000次扰动，给出±扰动范围与结果区间）
   - 合理性分析（可选）：变量选择合理性（领域依据+相关性检验排除无关变量）+ 模型结果合理性（指标提升链，如R²从0.0457提升至0.8037）
2. **模型的评价与推广**（`\section{模型的评价与推广}`）：
   - 优点：编号列表，每条扣具体机制（模型由简到繁递进、算法选择理由、约束物理可实现），禁止空泛
   - 缺点：编号列表，每条对应一个简化假设/局限，与模型假设呼应
   - 推广及改进方向：3条，具体可操作（引入新数据/新机制/在线滚动优化）
   - 参考文献与附录不写，留 `% TODO` 占位（本仓库约定）

## 摘要（全部问完成后最后写）

- 结构按《写作规范.md》第2节摘要四段式：背景 1-2 行 → "针对问题一/二/三/四"每问一段（做了什么+用什么模型+关键结果数值）→ 结尾一句模型评价；范文中的"综上所述/系统性解决"升华句禁用（见第11节冲突清单）
- 数值只从已写章节与 result_qN.xlsx 取，关键数值 `\textbf{}` 加粗；摘要内无公式；800-1000 字控制单页
- 填入 abstract 环境，同时定稿 `\biaoti{}` 与 `\keyword{}`（3-5个，含核心模型词）

## 收尾检查（全部问+摘要完成后）

符号表与正文一致 → 图表编号连续、`\ref` 交叉引用有效 → 数值与 result_qN.xlsx 逐项交叉核对 → risk_notice 坑点全文终查 → CLAUDE.md 禁用词全文扫描 → 完整编译一次交付

## 输出位置

- `论文/main.tex`（单文件，唯一交付物；唯一工作区，禁止写 `latex模板/`）
- 编译产物 main.pdf 同目录，供用户直接查看
